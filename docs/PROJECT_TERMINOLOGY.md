# Project Terminology

Consistent vocabulary prevents the 16 source-unavailable legacy functions
from being mischaracterized.

## Canonical terms

| Term                          | Meaning                                            |
| ----------------------------- | -------------------------------------------------- |
| OCF                           | Open Consciousness Functions                       |
| Function                      | A capability modeled independently of its audio    |
| Canonical command             | The OCF-preferred spoken cue (`PLUS-FOCUS`)        |
| Legacy command                | The historical command as documented               |
| Legacy source unavailable     | Original training material is not available to OCF |
| OCF reimplementation planned  | Valid target for original OCF scripts (status `planned`) |
| Command alias                 | A retained legacy/spoken alternative cue           |
| Bridge training               | A *designed* cue-association exercise (not science)|
| Audio implementation          | One concrete recording manifest for a function     |
| Background preset             | An optional synthesis bed, independent of scripts  |
| Evidence state                | How a claim is (or isn't) supported                |
| `pending-source-review`       | A placeholder for data not yet source-resolved     |

## Prohibited / discouraged terms

Use the correct phrasing instead:

| ✗ Avoid                          | ✓ Use                                 |
| -------------------------------- | ------------------------------------- |
| "missing functions"              | "legacy source unavailable"           |
| "orphaned functions"             | "OCF reimplementation planned"        |
| "Monroe audio recreated"         | "legacy source unavailable; OCF script" |
| "restored original audio"        | a labeled OCF reimplementation        |
| "guaranteed effect"              | "intended_effects / evidence state"   |

## Independence wording

OCF is "inspired by" the general idea behind Monroe Institute Human Plus, and
is an independent community project. Phrases that imply affiliation
("by The Monroe Institute", "official Hemi-Sync") are prohibited.

# Options command decision

The approved Options command presentation is stored in the canonical resource
[`OCF-COG-005`](../locales/en-US/OCF-COG-005-Options.yaml). Its historical
command phrase remains a lookup-only identity; it is not an active cue.

The canonical resource records the decision ID, approving source revision,
command identity, previous/current resolved-text SHA-256 values, and the count of
unchanged protected entries. It does not retain a second copy of predecessor
narration or function YAML. The current cue and narration are read from the same
locale resource used by runtime planning.

The decision did not approve listening, DSP/pacing changes, or release. Existing
recordings are validated against current text fingerprints and are never
relabelled as matching changed wording.

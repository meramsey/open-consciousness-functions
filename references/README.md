# References

Authoritative reference material for legacy mapping and source reviews.

## What lives here

- `*.pdf`, `*.mp3`, `*.wav`, etc. — **local analysis copies only**. These are
  typically copyright-protected, so they are gitignored and never distributed.
  Files you add here stay on your machine unless you explicitly license them.
- `references/uploads/` — copies made deliberately via `ocf import source`
  (only for material you are permitted to redistribute).
- Source-review notes belong in `legacy/source-notes/` or
  `templates/source-review.md`.

## Citation-only by default

OCF records concise factual mappings and short summaries. It does **not**
reproduce large copyrighted passages or redistribute third-party PDFs/audio.
Cite the material; keep the facts; keep the source files out of the repo.

## Detected sources

If `references/HPLUS_Field_Guide_Print.pdf` or
`references/HPLUS_Function_Index.pdf` are placed here, use them as the
authoritative legacy-reference sources and preserve page locators where
possible. Never invent data that a source does not support: record
`pending-source-review` instead.

# OCFP-0003: Analytical completeness with investigated unknowns

- Status: draft additive implementation
- Date: 2026-10-02

The specification's existing`extraction_status` gains a completion contract:
all16 analytical questions need explicit status, meaningful summary and locators;
full available-source extent is recorded and cross-checked against evidence
identity. Locator forms support transcript line/range or inspected PDF page.
Complete may retain unknown/not-present/not-applicable/inferred answers after
investigation. It does not promote maturity, authenticate source or bind runtime
states. Shared-format content groups remain relationship evidence only.
The manually authored review inputs preserve source/inference/OCF-design
boundaries; application validates source bytes, extent and resulting schemas.
Generated machine/human review views expose the same structured answers. No
function command format, source/reference files or localized narration is changed.

# Cosmic Path / Resonance Rings — 0.2.0 candidate

Original OCF geometry, evolved from the retained 0.1.0 candidate. This version
is not approved as the final brand. See the [comparison gallery](gallery/index.html)
and [renderer/workflow guide](../../../docs/BRANDING.md).

The source scene owns distinct logo, minimal icon, app tile, album and social
layouts. Gradients and luminous layers are procedural; no external artwork,
network service or font download is needed to view the exported SVGs.

The committed gallery is vector-only. Generate a new local gallery with PNG
previews using `ocf artwork refine --output .ocf-work/renders/NEW-DIRECTORY`.
Verify this source gallery with `ocf artwork refine --output
brand/versions/0.2.0/gallery --vector-only --check`. Do not hand-edit generated
SVGs or replace an earlier review directory. Geometry/code follow Apache-2.0;
font output retains the applicable font terms.
